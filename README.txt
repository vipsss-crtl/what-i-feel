HOW TO ACTIVATE EMAIL NOTIFICATIONS
1. Upload/host this website on a public HTTPS website.
2. Open the website and select one of the final three answers once.
3. FormSubmit will send an activation/confirmation email to vipulkatamble07@gmail.com.
4. Confirm the activation from that email.
5. After activation, future selections will be delivered to that email automatically.

IMPORTANT
- The website itself does not display the email address.
- No Netlify-specific code is required.
- The email is sent using FormSubmit's AJAX endpoint.
- If the website is opened only as a local file (file://), browser/network restrictions may prevent the request. Test it on a hosted HTTPS URL.
- WhatsApp cannot be silently sent from a normal website. A WhatsApp version can only open a pre-filled message for the user to send.
